# Mario Kart World PC Port (Eglantine-MKW 1.8.0)

Experimental `eden-nx2` fork tuned for **Mario Kart World** (`0400C3F00006E000`). Requires your own dumped cartridge/eShop files, firmware, and `prod.keys`.

<summary>Recommended 8GB & 16GB GPU Settings</summary>

- **Renderer**: Vulkan, `1x` scale, GPU Mode `Fast`, asynchronous shaders enabled.
- **VRAM Protection**: Automatic `BC3` ASTC texture recompression holds 8 GB cards near `6.6 GB` peak.
- **VSync**: `FIFO Relaxed` with atomic pipeline cache writes so interrupted runs never corrupt next boot.

### Loading Update `917504`
Drop `prod.keys` into `%APPDATA%\eden\keys\`, open `File > Load File`, and select `updates\917504\exefs\main` from your own v1.8.0 dump.
